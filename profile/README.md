# simpsonm09-org

Personal projects and developer tooling by [Max Simpson](https://github.com/simpsonm09).

This organization holds the original repositories. Development happens in personal forks under [@simpsonm09](https://github.com/simpsonm09), with pull requests back to the originals.

## The development setup

- [repo-standard](https://github.com/simpsonm09-org/simpsonm09-repo-standard) provides shared CI, linting, security scanning, and branch governance.
- [repo-template](https://github.com/simpsonm09-org/simpsonm09-repo-template) is the starting point for new projects; [repo-catalog](https://github.com/simpsonm09-org/simpsonm09-repo-catalog) tracks the fleet and its adoption policy.
- [maxstack](https://github.com/simpsonm09-org/simpsonm09-maxstack) composes the workspace AI tooling for OpenCode, Claude Code, GitHub Copilot CLI, and Pi, used through T3 Code.
- [org-ai-plugin](https://github.com/simpsonm09-org/simpsonm09-org-ai-plugin) supplies shared skills and conventions; [personal-ai-plugin](https://github.com/simpsonm09-org/simpsonm09-personal-ai-plugin) supplies personal preferences.
- [dev-setup](https://github.com/simpsonm09-org/simpsonm09-dev-setup) covers workstation tools, machine profiles, and local services.

## Projects to explore

- [Postman test utilities](https://github.com/simpsonm09-org/simpsonm09-postman-test-utils): shared collection testing, secret resolution, and response validation.
- [Playwright API wrapper](https://github.com/simpsonm09-org/simpsonm09-playwright-api-wrapper): browser scenarios exposed through an HTTP API for Postman and CI.
- [PokeAPI wrapper](https://github.com/simpsonm09-org/simpsonm09-pokeapi-wrapper): a FastAPI service and reference for generated OpenAPI contracts.
- [Browser calculator](https://github.com/simpsonm09-org/simpsonm09-browser-calculator): a small Dockerized FastAPI example built from the template.
- [OpenClaw homelab](https://github.com/simpsonm09-org/simpsonm09-openclaw-homelab): self-hosted gateway configuration, validation, and runbooks.

The organization also includes CRUD fixtures in Go, Rust, .NET, and NestJS, alongside earlier utility and capstone projects.
